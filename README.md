# Gym Tracker – Releases

Dieses Repository enthält **keinen Quellcode**. Hier werden nur die fertigen, signierten Android-APKs
von **Gym Tracker** veröffentlicht, einem privaten, werbefreien Workout-Logger für Krafttraining.

Alle Versionen findest du unter [Releases](https://github.com/Warnage/gym-tracker-releases/releases).

## Installieren und automatisch aktualisieren mit Obtainium

[Obtainium](https://github.com/ImranR98/Obtainium) prüft regelmäßig auf neue Releases und installiert Updates
direkt aus diesem Repo, ganz ohne Play Store.

1. **Obtainium installieren:** APK von den [Obtainium-Releases](https://github.com/ImranR98/Obtainium/releases)
   herunterladen (oder über F-Droid / IzzyOnDroid) und installieren. Android fragt dabei, ob der Browser bzw.
   Obtainium Apps installieren darf – erlauben.
2. In Obtainium auf **„App hinzufügen“** tippen.
3. Als URL dieses Repo eintragen:
   ```
   https://github.com/Warnage/gym-tracker-releases
   ```
4. **„Hinzufügen“** tippen, dann **„Installieren“**.

Ab jetzt meldet Obtainium neue Versionen und installiert sie per Fingertipp. Deine Trainingsdaten bleiben bei
Updates erhalten, weil alle Versionen mit demselben Schlüssel signiert sind.

## Manuell

Alternativ die neueste `.apk` unter [Releases](https://github.com/Warnage/gym-tracker-releases/releases)
herunterladen und auf dem Handy öffnen.
